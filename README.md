# 💼 애터미 하부회원 CRM Pro (Atomy Downline CRM)

애터미 사업자 및 팀 리더를 위한 **전용 하부회원 관리 & 타겟팅 문자 마케팅 솔루션**입니다.  
스마트폰과 PC 브라우저에서 터치 한 번으로 계보도를 확인하고, 회원별 특이사항을 기록하며, 상태에 맞춰 개인 이름이 치환된 단체문자 파일을 1초 만에 추출할 수 있습니다.

---

## 🌟 핵심 기능 4가지

### 1. 📋 하부회원 프로필 & 특이사항 메모장 (CRM)
- **핵심 정보 관리**: 회원번호, 성명, 연락처(클릭 즉시 통화/문자 연결), 가입일, 후원인, 좌·우 라인 구분
- **실전 영업 메모**: 관심 제품(헤모힘, 스킨케어 등), 최근 주문 내역, 건강 고민, 가족 관계 등 자유로운 상담 메모 누적
- **문자 발송 히스토리**: 어떤 템플릿의 문자를 언제 보냈는지 회원 카드에 자동으로 기록

### 2. 🎯 스마트 필터링 & 세그먼트 타겟팅
- 원클릭 탭 분류:
  - `신규가입` : 앱 로그인 및 쇼핑몰 이용 안내가 필요한 회원
  - `반응·관심자` : 문자 확인 후 질문을 남기거나 제품에 관심을 보인 회원
  - `재구매도래` : 헤모힘 등 주요 제품 소진 주기가 다가온 재구매 타겟
  - `최근구매자` : 배송 안부 및 섭취/사용 팁 안내 대상
  - `핵심파트너` : 팀 미팅 및 세미나 프로모션 대상
- 좌측 라인 / 우측 라인 독립 필터 지원

### 3. 🌳 좌·우 바이너리 계보도(조직도) 트리 맵
- 스폰서(본인)를 중심으로 좌측 라인(블루)과 우측 라인(그린)의 하부 조직을 시각적 트리 맵으로 변환
- 계보도 노드에서 회원을 누르면 해당 회원의 상세 정보와 특이사항 메모가 즉시 팝업

### 4. 💬 타겟 맞춤 문자 생성기 (스마트폰 무료문자 연동)
- **1초 타겟팅**: 원하는 그룹(예: '재구매도래자 3명' 또는 '반응자 전체')을 클릭 한 번으로 선택
- **실전 템플릿**:
  - [신규가입] 웰컴 & 모바일 쇼핑몰 적립 안내
  - [재구매도래] 환절기 건강 안부 & 소진 시점 체크
  - [반응·관심자] 1:1 맞춤 후속 케어 & 감사 인사
  - [프로모션/세미나] 신상품 및 원데이 세미나 안내
- **개인화 치환**: 본문 속 `{이름}`과 `{회원번호}`가 실제 회원 정보로 자동 치환되어 1:1 개인 문자처럼 발송
- **원클릭 파일 다운로드**: 플레이스토어의 단체문자 앱(스마트 단체문자, 알리고 등)에 바로 넣을 수 있는 **엑셀 파일(.xlsx)** 즉시 다운로드 (비용 0원)

## 📱 스마트폰 무료문자 발송 3단계 실전 가이드

1. **CRM 웹앱에서 명단 추출**:
   - `맞춤 문자 생성기` 탭에서 대상 그룹 선택 ➡️ 템플릿 선택 ➡️ `📥 폰 무료문자 앱용 엑셀 다운로드` 클릭
2. **플레이스토어 단체문자 앱 실행**:
   - '스마트 단체문자' 또는 '알리고 폰문자' 등 무료문자 지원 앱 실행
   - 다운로드한 엑셀 파일 불러오기
3. **0원 무료 발송**:
   - 내 폰 요금제의 무료문자를 통해 1초에 1명씩 자동으로 발송 완료!
   - (※ 통신사 스팸 방지 규정상 하루 최대 500건까지 무료 발송 가능)

## 🚀 Streamlit Cloud 1분 무료 웹 배포 방법

1. 본 폴더(`atomy_crm_pro`)의 파일들을 은미님의 GitHub 저장소에 푸시합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속하여 로그인합니다.
3. `New app` 클릭 ➡️ 저장소 선택 ➡️ Main file path에 `app.py` 입력 ➡️ `Deploy!` 클릭
4. 1~2분 뒤 나만의 전용 웹사이트 주소(URL)가 생성되며, 스마트폰 홈 화면에 바로가기 아이콘을 추가해 앱처럼 쓰실 수 있습니다.
