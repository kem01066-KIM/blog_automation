# 🚰 바로누수 마케팅 원클릭 자동 생성기

바로누수의 예전 블로그 글 링크와 오늘 발행할 타겟 지역만 입력하면, **상위노출 제목 3선 + 5단계 완성형 원고 + STEP 라벨 편집 사진(개별 저장) + 15초 9:16 숏폼 영상(H.264)**을 원클릭으로 완성해 주는 프로그램입니다.

---

## 📱 스마트폰과 PC 어디서든 쓰는 방법 (Streamlit Cloud 무료 배포)

은미 님의 GitHub(`kem01066-KIM/blog_automation`)를 이용해 배포하고, 스마트폰과 PC 어디서든 웹 링크로 접속해 사용할 수 있습니다.

### Streamlit Community Cloud 배포 설정
1. [share.streamlit.io/deploy](https://share.streamlit.io/deploy)에 접속합니다.
2. 입력창 3가지를 아래와 같이 입력합니다:
   - **Repository**: `kem01066-KIM/blog_automation`
   - **Branch**: `baro-marketing`
   - **Main file path**: `app.py`
3. 파란색 **Deploy** 버튼을 누릅니다.
4. 배포 완료 후 스마트폰 브라우저 메뉴에서 **'홈 화면에 추가'**를 누르면 바탕화면에 전용 앱 아이콘이 생깁니다.

---

## ✨ 주요 기능 및 모바일 최적화

1. **상위노출 제목 3선 & 5단계 완성형 원고**
   - 네이버 스마트블록 알고리즘 반영 CTR 최적화 제목 3종
   - 현장 요약 카드, 5단계 현장 일지, 일상생활배상책임보험(일배책) 서류 지원 문구 자동 삽입
   - 에디터 붙여넣기용 복사 및 `.txt` 저장 지원

2. **사진 압축 없는 원클릭 개별 저장 (스마트폰 최적화)**
   - 압축(ZIP) 풀기 번거로운 폰 환경을 위해 각 사진별 **[📥 사진 저장]** 버튼 제공
   - 선명도 보정 + `STEP 01` 라벨 + `바로누수설비` 워터마크 + 하단 공정 설명 자막 자동 합성

3. **15초 세로 9:16 숏폼 영상 (H.264 MP4)**
   - 가공된 사진들을 엮어 블러 배경, Ken Burns 줌인, 상단 진행 바를 넣은 릴스·쇼츠용 세로 영상 자동 렌더링
   - 모바일 전 기종에서 즉시 재생 및 갤러리 저장 지원

## 💻 터미널 커맨드 한 줄로 실행하기 (CLI)

```bash
python cli_run.py --url "https://m.blog.naver.com/dnjswo3482/224052764862" --region "대구 북구 노원동"
```
- 실행 즉시 `결과물_대구_북구_노원동/` 폴더에 원고, 가공 사진(개별), 숏폼 영상이 저장됩니다.
