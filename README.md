# 🚰 바로누수 마케팅 원클릭 자동 생성기

바로누수의 예전 블로그 글 링크와 오늘 발행할 타겟 지역만 입력하면, **상위노출 제목 3선 + 5단계 완성형 원고 + STEP 라벨 편집 사진 + 15초 9:16 숏폼 영상**을 원클릭으로 패키징해 주는 프로그램입니다.

---

## 📱 PC와 스마트폰 어디서든 쓰는 방법 (권장: Streamlit Cloud 무료 배포)

은미 님의 GitHub(`kem01066-KIM`)를 이용해 5분 만에 무료로 배포하고, 스마트폰과 PC 어디서든 웹 링크로 접속해 사용할 수 있습니다.

### 1단계: 깃허브에 코드 올리기
1. 깃허브에 새 리포지토리 생성 (예: `baro-marketing`)
2. 이 폴더의 파일들(`app.py`, `requirements.txt`, `README.md`)을 업로드합니다.

### 2단계: Streamlit Community Cloud 배포 (무료)
1. [share.streamlit.io](https://share.streamlit.io/)에 접속하여 깃허브 계정으로 로그인합니다.
2. `New app` 클릭 후 방금 만든 `baro-marketing` 리포지토리를 선택하고 `Deploy`를 누릅니다.
3. 2~3분 뒤 나만의 고유 웹 주소(예: `https://baro-marketing.streamlit.app`)가 생성됩니다.

### 3단계: 스마트폰에서 앱처럼 쓰기
- 스마트폰(갤럭시 크롬 등)에서 위 주소로 접속합니다.
- 브라우저 메뉴(점 3개)에서 **'홈 화면에 추가'**를 누르면 스마트폰 바탕화면에 전용 앱 아이콘이 생깁니다!
- 현장이나 이동 중에도 링크와 지역만 넣고 버튼을 누르면 원고와 사진, 15초 영상까지 스마트폰에 바로 다운로드됩니다.

## 💻 PC 로컬에서 바로 실행하기

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 웹앱 실행
streamlit run app.py
```
- 실행 시 터미널에 뜨는 `Network URL`을 사용하면, 같은 와이파이에 연결된 스마트폰에서도 바로 접속할 수 있습니다.
