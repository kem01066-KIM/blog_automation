# 🎯 Signal Room · 인플루언서 발굴기 (모바일 완벽 호환)

복잡한 네이버 검색 API 키나 Meta Graph API 토큰 없이, 스마트폰과 PC에서 실시간으로 네이버 블로그 및 인스타그램 공구·체험단 인플루언서를 발굴하고 영구 보관하는 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **API 키 100% 불필요 (무설정 즉시 실행)**:
   - 네이버 블로그 실시간 검색 및 본문·제목·작성일자 자동 수집
   - 인스타그램 공개 프로필 및 공구/협찬 신호 실시간 발굴
2. **AI 적합도 평가 엔진**:
   - 공구 적합도 (0~100점): '공구', '마켓', '최저가', '오픈', '프로필링크' 등 상업적 전환 키워드 분석
   - 체험단 적합도 (0~100점): '협찬', '제공받아', '솔직후기' 등 리뷰 신호 분석
3. **영구 보관함 (SQLite 내장)**:
   - 서버가 꺼져도 사라지지 않는 로컬 데이터베이스
   - 공구/체험단 목적별, 진행상태별(검토중/컨택완료/협업확정) 관리
   - 엑셀(CSV) 원클릭 일괄 다운로드 지원
4. **스마트폰 원클릭 연동**:
   - 후보 링크 클릭 시 스마트폰의 네이버 블로그 앱 / 인스타그램 앱으로 즉시 연결
   - 터치 친화적 카드형 모바일 UI

---

## 📱 스마트폰 홈 화면에 앱으로 추가하는 방법 (Streamlit Cloud 무료 배포)

1. GitHub 저장소에 코드를 푸시합니다.
2. [share.streamlit.io](https://share.streamlit.io)에 접속하여 GitHub 저장소와 `app.py`를 선택하고 Deploy를 누릅니다.
3. 배포 완료 후 발급된 URL(`https://xxxxx.streamlit.app`)을 스마트폰 브라우저(크롬/삼성인터넷/사파리)로 엽니다.
4. 브라우저 메뉴에서 **'홈 화면에 추가'**를 누르면 스마트폰 앱처럼 원터치로 실행할 수 있습니다.
