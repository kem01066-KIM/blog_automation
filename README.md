# 📱 소상공인 안드로이드 스마트 콜백 매니저 Pro (Smart Callback Pro)

소상공인 사장님이 고객과 통화를 마치거나 부재중 전화를 받았을 때, **네이버 플레이스 지도 링크, 매장 약도, 영업시간, 주차 안내, 맞춤 문구**를 고객 스마트폰으로 즉시 자동 발송하는 안드로이드 전용 콜백 서비스입니다.

---

## 🌟 핵심 기능

1. **5대 대표 업종별 실전 문구 템플릿 내장 (원클릭 세팅)**
   - 🍽️ **식당/맛집**: 오시는 길, 전용 주차장, 영업시간, 네이버 플레이스/예약 링크
   - 🔧 **인테리어/설비/누수**: 긴급 출장 접수, 현장 사진 전송 안내, 시공 사례 블로그 링크
   - 💇 **미용/뷰티/네일**: 100% 우선 예약제 안내, 오시는 길, 네이버 실시간 예약 링크
   - 📚 **학원/교습소/스터디**: 상담 운영시간, 레벨테스트 및 커리큘럼 링크
   - 💼 **부동산/일반 소상공인**: 모바일 명함, 확인된 실매물 리스트, 홈페이지 링크

2. **통화 상황별 3대 자동 분기 발송**
   - 📞 **정상 통화 종료 후**: 통화 감사 인사 및 매장 위치/플레이스 링크 전달
   - 🚫 **부재중 전화 시**: 조리/작업 중 양해 인사 및 문자로 용건 남기기 유도
   - 🌙 **영업 외/휴무 시간**: 영업시간 안내 및 다음 영업일 우선 회신 약속

3. **스마트 안심 발송 룰 엔진 (스팸 피로도 원천 차단)**
   - 🛡️ **동일 번호 1일 1회 제한**: 하루에 같은 손님과 여러 번 통화해도 문자는 1회만 발송
   - ⏳ **자연스러운 지연 발송**: 통화 종료 후 3~5초 뒤 자연스럽게 도착하도록 지연 타이머 적용
   - 🚫 **발송 제외 번호(블랙리스트) 관리**: 가족, 직원, 고정 거래처 등 문자가 가면 안 되는 번호 완벽 차단

4. **실시간 갤럭시 스마트폰 수신 화면 프리뷰**
   - 고객 폰에 실제로 문자가 어떻게 도착하는지 실시간 말풍선 뷰어 제공
   - 통신사 SMS(단문 90B) vs LMS(장문 2000B) 용량 자동 계산

5. **안드로이드 폰 1분 연동 & 제로 비용 (문자비 0원)**
   - 안드로이드 통신사 요금제에 포함된 기본 무료 문자(하루 500건)를 활용하여 추가 비용 0원
   - 안드로이드 자동화 무료 앱(MacroDroid/Tasker) 원클릭 연동 지원 및 Termux 백그라운드 데몬 지원

---

## 🚀 실행 및 배포 방법

### 1. 로컬 또는 Streamlit Cloud 웹앱 실행
```bash
streamlit run app.py
```

### 2. 안드로이드 기기 연동 (2가지 방법)

#### [방법 A] 안드로이드 무료 자동화 앱 (MacroDroid / Tasker) - 1분 완성 (가장 추천)
1. 구글 플레이스토어에서 무료 앱 **MacroDroid** 설치
2. **트리거**: [통화] ➡️ [통화 종료됨]
3. **작업**: [SMS 발송] ➡️ 본 웹앱에서 [설정 파일 다운로드]로 추출한 문구 등록
4. 이제 통화가 끝날 때마다 사장님 폰에서 고객에게 무료 문자가 자동으로 전송됩니다!

#### [방법 B] Termux 파이썬 데몬 구동
안드로이드 Termux 환경에서 백그라운드 리스너 구동:
```bash
python android_daemon.py --server --port 8080
```
