# Place Insight Pro — 네이버 스마트플레이스 운영 진단 & 새소식 스튜디오 Pro

네이버 스마트플레이스 운영 사장님들을 위한 100점 만점 정밀 진단 시스템 및 고전환 새소식 자동 작성 솔루션입니다.

## 주요 기능
- **4대 핵심 영역 100점 만점 진단**: 정보 정확도, 특장점 반영도, 사진·메뉴 콘텐츠, 고객 전환 장치(예약/톡톡/쿠폰/새소식)
- **사장님 강점 vs 실제 반영도 팩트 체크**: '단체 가능', '주차 편리', '놀이방' 등 사장님이 생각하는 강점이 실제 플레이스에 얼마나 반영되어 있는지 진단
- **이번 주 15분 실행 과제 TOP 3**: 스마트플레이스 센터 모바일 앱에서 15분 만에 고칠 수 있는 우선순위 액션 가이드
- **경쟁업체 정보 공백 비교표**: 상위 1~3위 경쟁 매장 대비 내 가게의 누락된 정보 비교
- **새소식 스튜디오 (원클릭 AI 작성기)**: 단체 모임, 주차 안내, 시그니처 메뉴 등 5대 테마별 고전환 새소식 초안 및 사진 가이드 제공
- **카톡 전송용 요약 리포트**: 소상공인 미팅이나 컨설팅 후 1초 만에 카카오톡으로 전송할 수 있는 텍스트 브리핑

## 실행 방법
```bash
streamlit run app.py
```
