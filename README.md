# 🧵 스레드 제휴마케팅 썰 글 생성기 (Threads Affiliate Pro)

> **수강생을 위한 원클릭 스레드 썰 글 생성 & 제휴마케팅 자동화 웹 솔루션**

쿠팡 파트너스, 네이버 브랜드 커넥트, 스마트스토어 등 상품 링크와 핵심 키워드만 넣으면, 스레드(Threads)에서 도달률과 저장률이 터지는 **1인칭 썰 글 3종(내돈내산 찐후기 / 호구방지 비교 / 일상공감 꿀팁)과 법적 필수 공정위 문구**를 3초 만에 생성해 주는 가볍고 직관적인 웹 앱입니다.

---

## 🌟 주요 특징

1. **설치 스트레스 ZERO (웹 브라우저 100% 구동)**
   - 복잡한 데스크톱 프로그램, Node.js, Codex CLI 설치 불필요
   - 모바일 스마트폰과 PC 웹 브라우저 어디서나 링크만 넣고 [생성] 누르면 끝!

2. **스레드 알고리즘 맞춤 3대 썰 글 엔진**
   - **A타입 [내돈내산 찐후기형]**: 바이럴 의심 극복 ➡️ 실사용 1달 체감 만족 ➡️ 자연스러운 구매 유도
   - **B타입 [호구방지 비교분석형]**: 거품 낀 대기업 스펙 비교 ➡️ 가성비 실속 종결 ➡️ 합리적 소비 심리 자극
   - **C타입 [일상공감 삶의질형]**: 퇴근길 스트레스 공감 ➡️ 생활 피로 해소 솔루션 ➡️ 공감대 폭발

3. **스레드 도달률 최적화 분리 출력 (댓글 링크 모드)**
   - 본문에 제휴 링크를 대놓고 달면 메타 알고리즘에 의해 도달률이 90% 이상 깎이는 현상 원천 차단
   - **1️⃣ 스레드 본문 썰 글**과 **2️⃣ 첫 댓글용 링크+공정위 문구**를 각각 원클릭으로 복사할 수 있도록 완벽 분리

4. **100% 법적 컴플라이언스 준수**
   - 공정거래위원회 '추천·보증 등에 관한 표시·광고 심사지침'에 따른 경제적 이해관계 표준 문구 자동 삽입

## 🚀 수강생 무료 배포 방법 (Streamlit Cloud 3분 컷)

은미님이 수강생들에게 웹 링크 하나로 공유하는 가장 깔끔한 방법입니다.

1. **GitHub 저장소에 올리기**
   - 본 폴더(`threads_affiliate_pro`)의 파일들을 은미님의 GitHub 계정(예: `kem01066-KIM/threads-affiliate-pro`)에 푸시합니다.
2. **Streamlit Community Cloud 접속**
   - [share.streamlit.io](https://share.streamlit.io/)에 접속해 GitHub 로그인
3. **[New app] 클릭 ➡️ 배포 완료!**
   - Repository: `threads-affiliate-pro`
   - Main file path: `app.py`
   - [Deploy!] 누르면 1분 만에 `https://xxx.streamlit.app` 형태의 전용 웹 주소가 생성됩니다.
4. **수강생에게 링크 전달**
   - 수강생은 회원가입이나 설치 없이 폰에서 링크 열고 바로 사용합니다.

## 💡 스레드 제휴마케팅 성공 3대 수칙 (수강생 지도 팁)

1. **일상 7 : 홍보 3 황금 비율**
   - 하루에 글을 3개 올린다면 2개는 일상·공감·유머 글, 1개만 제휴 썰 글로 올리세요. 계정이 광고판으로 낙인찍히면 영구 정지됩니다.
2. **첫 댓글 링크 고정**
   - 본문에는 오직 재미있는 썰만 풀고, "제가 샀던 최저가 링크는 첫 댓글에 남겨둘게요!"라고 적은 뒤 본인 글에 첫 댓글로 링크를 다는 것이 도달률 5배의 비밀입니다.
3. **단가 계산 멘트 넣기**
   - "개당 800원 꼴", "하루 300원으로 손목 통증 끝"처럼 고객이 계산기를 두드리지 않아도 싸다고 느끼는 단가 멘트를 꼭 섞어주세요.
